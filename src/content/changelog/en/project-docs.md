The homepage has long shown "Architecture: documented, Decisions: recorded",
but the documents were not linked from anywhere. This update makes the claim
true: Sakala's project documents now live in this site's repository and are
published on the Project track.

Fifteen canonical documents — PHILOSOPHY, VISION, PRD, MVP, ARCHITECTURE,
ADR, SECURITY, ROADMAP, DESIGN_STRATEGY, FEATURE_EXPLORE, FEATURE_EDUCATION,
PLATFORM_OPERATIONS, GOVERNANCE, CONTRIBUTING, GLOSSARY — appear in their
original language on both language routes, deliberately untranslated so
there is a single source. Each page states that it is canonical and which
language it is written in. There is no separate documentation repository;
a change on this track is a project decision and is reviewed by maintainers.

The openness evidence on the homepage and the Open Source page can now be
opened: Architecture leads to the architecture document, Decisions to the
ADRs. The Philosophy, Roadmap, and technical documentation pages link to
their canonical sources.

A Design System page opens on the Technical track: color tokens with
measured contrast, the typography pair, spacing scale, status vocabulary,
and artifact rules — the reference for anyone building a Sakala interface.
