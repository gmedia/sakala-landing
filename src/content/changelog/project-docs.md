Beranda sudah lama memajang "Arsitektur: terdokumentasi, Keputusan:
tercatat", tetapi dokumennya tidak ditautkan dari mana pun. Pembaruan ini
menjadikannya benar: dokumen project Sakala kini hidup di repository situs
ini dan diterbitkan di jalur Proyek.

Lima belas dokumen kanonik — PHILOSOPHY, VISION, PRD, MVP, ARCHITECTURE, ADR,
SECURITY, ROADMAP, DESIGN_STRATEGY, FEATURE_EXPLORE, FEATURE_EDUCATION,
PLATFORM_OPERATIONS, GOVERNANCE, CONTRIBUTING, GLOSSARY — tampil dalam bahasa
aslinya di kedua route bahasa, sengaja tidak diterjemahkan supaya sumbernya
tunggal. Tiap halaman menyebutkan statusnya sebagai dokumen kanonik dan
bahasanya. Tidak ada repository dokumentasi terpisah; perubahan di jalur ini
adalah keputusan project dan ditinjau maintainer.

Bukti keterbukaan di beranda dan halaman Open Source kini bisa dibuka:
Arsitektur menuju dokumen arsitektur, Keputusan menuju ADR. Halaman
Filosofi, Roadmap, dan dokumentasi teknis menautkan sumber kanoniknya.

Halaman Sistem Desain dibuka di jalur Teknis: token warna dengan rasio
kontras terukur, pasangan tipografi, skala spasi, kosakata status, dan
aturan artefak — patokan bagi siapa pun yang membuat antarmuka Sakala.
