# Visi Produk Sakala

> **From possibility to manifestation. From manifestation to growth.**

## North Star

Sakala ingin menjadi developer platform terbuka yang membantu manusia membawa software melalui seluruh perjalanan:

```text
Create
→ Manifest
→ Operate
→ Share
→ Learn
→ Collaborate
→ Grow
```

Deployment adalah jantung Sakala, tetapi bukan seluruh tubuhnya.

## Product Pillars

## 1. Create

Membantu developer memulai dari source atau starting point yang baik.

Capabilities:

- connect Git repository;
- starter templates;
- application templates;
- examples;
- official templates;
- community templates;
- education templates;
- Deploy to Sakala button;
- future remix/use-as-starting-point.

Primary question:

> Dari mana karya ini dimulai?

## 2. Manifest

Membawa source menjadi aplikasi nyata.

Capabilities:

- repository analysis;
- stack detection;
- Dockerfile;
- Railpack;
- manual build/start override;
- deployment;
- deployment stages;
- web service;
- future worker;
- future cron;
- static site;
- health check;
- generated public URL;
- redeploy;
- rollback/recovery;
- future environments and preview deploy.

Primary question:

> Bagaimana source ini menjadi sesuatu yang hidup?

## 3. Operate

Membantu aplikasi tetap dapat digunakan dan dipahami setelah deployment.

Capabilities:

- variables/secrets;
- generated domain;
- custom domain;
- DNS verification;
- TLS;
- logs;
- health;
- resource profile;
- metrics;
- restart information;
- future alerts;
- managed PostgreSQL;
- Redis/Valkey;
- object storage;
- worker/queue;
- usage/quota.

Primary question:

> Setelah hidup, bagaimana aplikasi ini dijaga?

## 4. Explore

Membuat karya dapat ditemukan, dilihat, dipelajari, dan digunakan kembali.

Capabilities:

- public project showcase;
- templates;
- creator profile;
- collections;
- featured projects;
- official/community/education collections;
- template submission;
- moderation;
- source attribution;
- live demo;
- project lineage;
- future remix.

Primary question:

> Apa yang dapat lahir dari karya yang sudah hidup?

## 5. Collaborate

Membawa deployment dari individu menuju kelompok.

Capabilities:

- personal workspace;
- team workspace;
- member;
- role;
- invite;
- project transfer;
- activity;
- audit;
- organization profile;
- shared templates/collections.

Primary question:

> Bagaimana karya dikelola bersama?

## 6. Learn

Memberi tempat bagi proses belajar software delivery nyata.

Capabilities:

- classroom;
- workshop;
- internship/PKL workflow;
- assignment;
- starter template;
- deployment submission;
- instructor/mentor overview;
- resource policy;
- project showcase;
- future institutional workspace.

Boundary:

```text
Sakala Learn
≠ LMS
```

Sakala tidak mengelola materi kuliah, presensi, ujian, dan kurikulum.

Sakala mengelola:

```text
source
→ deployment
→ live application
→ submission/review
```

## 7. Platform

Memberi power user dan operator akses lebih luas.

Capabilities:

- CLI;
- public API;
- API tokens;
- deploy hooks;
- webhooks;
- self-host installer;
- node join;
- node drain;
- node upgrade;
- runtime roles;
- future multi-node;
- future router/gateway.

## 8. Operations

Memberi maintainer kemampuan menjaga Sakala tetap sehat.

Capabilities:

- user/project/deployment visibility;
- runtime nodes;
- capacity;
- failed commands;
- deployment failure analytics;
- resource/abuse signal;
- template moderation;
- showcase moderation;
- feedback;
- announcements;
- audit;
- product validation metrics.

```text
Vision broad.
Execution narrow.
```

## What Sakala Must Not Become

Sakala tidak boleh kehilangan identitas karena mengejar feature parity.

Hindari menjadi:

- generic cloud dashboard;
- Kubernetes UI dengan nama baru;
- social network developer;
- LMS;
- domain registrar;
- observability suite pengganti Grafana;
- AI-branded cloud tanpa core value;
- infrastructure playground yang lebih menyenangkan maintainer daripada user.

Setiap extension harus kembali pada:

> **Manifesting Code into Reality.**
