01 / Distance

Tidak semua yang selesai dibuat, selesai diwujudkan.

Berjalan di laptop bukan berarti dapat dijangkau. Tersimpan di repository bukan berarti telah hidup.

Ada jarak kecil tetapi penting antara “I built this.” dan “Here it is.”

04 / Clarity

Sederhana tidak harus berarti tersembunyi.

Otomasi boleh mengurangi kompleksitas. Tetapi ketika sesuatu gagal, developer tetap berhak memahami apa yang terjadi.

Sakala explains

Application started, but did not respond on port 8080.

Prosesnya tidak hilang di balik “something went wrong”. Ada konteks yang bisa dipahami dan diperbaiki.

  • → check bind address
  • → check exposed / expected port
  • → inspect runtime logs

Magic boleh terjadi. Misteri tidak harus.
